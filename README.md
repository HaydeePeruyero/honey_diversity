# Uncharacterized *Acetilactobacillus*-like genera represent the most abundant microorganisms in honeys produced by native stingless bee

This study includes the following samples:: 

- 8 from *Melipona beecheii* in the Yucatan Peninsula (Santa Gertrudis, Jose Maria Morelos and Mani).

- 9 from *Scaptotrigona mexicana* in Papantla, Veracurz (Aguateno, El Colorado, and La Isla).

Beekiping methods: 

- *S. mexicana*: modern boxes, blended honey, and traditional pitchers. 

- *M. beecheii*: boxes, blend, and log hives jobones.
